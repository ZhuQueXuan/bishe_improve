## 目标与固定边界

这是申请Agent相关实习前的练手项目，目标是能运行、讲清、验证技术机制；随后进入Mini SWE Agent主项目。不要无限扩张成大型医疗产品。

- 唯一源码：`../bishe/`，运行说明[README](../bishe/README.md)。Old不参与运行。
- 全量图谱已经启用：medical_full_v1，8,806疾病、27,098业务实体、301,314关系；使用项目`scripts/start.ps1`，不启动安装默认库，不重新导入。
- Neo4j、原始`bishe/data/medical.json`及正式`knowledge_graph_backend/db.sqlite3`不用于实验写入；验收用游客接口、内存账号库、模拟模型或只读图谱。
- 本地小模型、向量索引/embedding/三路融合取消当前路线，不恢复或下载；检索细节优化暂缓；不预设多Agent、长期画像。
- 临时脚本、日志、checkpoint和构建材料放根`temp/`。禁止批量删除。不输出.env或密钥。
- 用户此前明确允许DeepSeek直接测试，仍限定批次范围/次数/费用；旧批次全部结束，不自动用余额。2026-10-05首次正式小样本已用3次、估算0.052623264元并停止；用户随后明确批准修复后新批最多16次/估算2元；实际13次/估算0.050975520元，已结束不自动使用余额。两批合计16次/估算0.103598784元。
- 用户不需要可运行演示；最终项目讲解等正式版验收完成后进行。

| 输入变化 | 不再将最近10条完整对话交给回答模型；只外发当前问题、有效状态及当次证据。指代通过本地显式对象归一化；有消息来源编号，不把讨论对象当病历 |
| 保存后继续 | temp短期checkpoint+签名账号/会话绑定+一次原子占用；恢复沿用原90秒截止/已花预算；页面“先看关联结果/继续整理”可用，不属于长期任务保存 |
| 最终回答 | 一次生成，只接受完整响应和当前证据编号；不接受伪造编号；来源接口保留；表格按安全文本显示；三阶段显式关闭默认思考 |
| 历史与隔离 | 登录历史按账号/会话隔离，从既有记录重建状态，无schema迁移；游客本次多会话，刷新清空；实验不写正式账号库 |
