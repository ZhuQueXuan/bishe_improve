## 阶段目标

用可复现的测试和对照实验说明 Graph-RAG 与 Agent 工具调用的实际价值，并形成可展示、可讲解的项目材料。

- [x] 建立 50 个固定资料检索问题。
- [x] 标注目标实体、字段/关系与原文证据期望；不作为医学答案标准。
- [ ] 对比仅大模型、仅图谱检索和 Hybrid Graph-RAG Agent。

- [ ] 完成整体响应时间和模型调用成本统计；已有检索耗时及21当次查询理解时延/用量估算，缺最终端到端统计。
- [ ] 制作可重复的演示流程。
- [ ] 完善项目 README、架构说明和面试讲解材料。

## 主要指标

- 实体识别正确率；
- Recall@K；
- 图谱关系命中率；
- 引用证据正确率；
- 回答忠实度；
- 无证据时的拒答正确率；
- 平均响应时间；
- 单次问答模型成本。

## 医疗场景要求

- 明确标注内容仅供知识查询和学习参考。
- 不将回答包装成诊断或处方。
- 高风险问题提示用户寻求专业医疗帮助。
- 数据冲突或证据不足时不生成确定性医疗结论。

## 验收标准

- 能够重复运行同一套评测。
- 能够用数据说明各检索模块的贡献。
- 能够展示至少一个成功案例和一个失败案例。
- 项目 README 能让新协作者完成启动、演示和核心流程理解。
