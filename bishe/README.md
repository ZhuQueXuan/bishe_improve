### 账号备份与恢复演练

命令行等价入口为`python scripts/backup-account.py`。程序用SQLite一致性备份接口、以只读方式打开来源，并检查新副本完整性与外键；目标存在就停止，不提供覆盖正式账号库的开关。

演练恢复时，使用同一程序把选定备份复制成另一个新文件：

```powershell
& .\knowledge_graph_backend\.venv\Scripts\python.exe -B .\scripts\backup-account.py --source "备份完整路径.sqlite3" --output "已存在目录\全新恢复副本.sqlite3"
```

本轮只在恢复副本中验证写入，正式账号库没有被替换。实际灾难恢复时先停止服务，核验备份版本和数据，再单独决定是否切换正式库；不要用旧备份覆盖新聊天。整个项目的恢复还需要Neo4j正常停机备份、完整专业资料目录和Qdrant快照，账号备份不能代替这些材料。

## 首次配置

1. 安装 Python 3.10、Node.js、Java 17 和 Neo4j 5。
2. 在 `knowledge_graph_backend` 中创建 `.venv`，安装该目录下的 `requirements.txt`。

## 前端第一版交互

- 访问前端后直接进入大模型对话工作区，旧的系统仪表盘和图谱管理页不再暴露给普通用户。

## 最小 Agent 与离线演示
