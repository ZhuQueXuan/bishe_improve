## 首次配置

1. 安装 Python 3.10、Node.js、Java 17 和 Neo4j 5。
2. 在 `knowledge_graph_backend` 中创建 `.venv`，安装该目录下的 `requirements.txt`。
3. 进入 `knowledge-graph-frontend` 安装前端依赖。
4. 将 `knowledge_graph_backend/.env.example` 复制为同目录的 `.env`，填写本地配置和 API 密钥。

真实 `.env` 只保存在本机，不应提交或发送给其他人。后端运行所需的 Django、Neo4j 和 DeepSeek 配置都集中在该文件中。

## 目录边界

- `knowledge_graph_backend/`：Django 后端、`.env`、`.venv` 和 Python 依赖清单。
- `knowledge-graph-frontend/`：Vue 前端、Node 依赖和前端 API 地址示例。
- `scripts/`：统一启动、停止、健康检查和密钥配置脚本。

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\health-check.ps1
```

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\stop.ps1
```

停止脚本只处理最近一次由 `start.ps1` 启动并记录的进程；启动前已经存在的服务不会被脚本强行停止。

## 前端第一版交互

- 访问前端后直接进入大模型对话工作区，旧的系统仪表盘和图谱管理页不再暴露给普通用户。
- 游客无需注册就可以使用图谱增强问答，但刷新页面后不保留对话。
- 注册用户登录后可以创建、切换、搜索和删除历史会话。
- 注册用户的会话和每条消息保存在 Django 后端数据库，并通过 Token 鉴权隔离不同用户数据。
- 每次问答从当前会话的用户消息重建显式讨论对象和有效要求（最多2000条），取消/更正/换话题优先。向DeepSeek发送当前问题、有效结构状态及检索资料，不继续发送最近10条完整旧对话。游客状态刷新清空，登录会话状态从该账号已有历史重建。
- 多步资料整理支持从一个疾病的并发关系中按名称排序选前2项（不足2项全部），继续读取描述/预防并组织回答。普通图谱/全文查询保留；这是有限范围的动态规划。
- 多步任务勾选“先看关联结果”可保存进度，再点“继续整理”。恢复凭证绑定账号/会话，仅使用一次，沿用原90秒截止和剩余预算；不用于长期任务保存。
- 模型表格以安全文本单元格显示，继续按钮和整理依据接在同一个正式聊天页面。
- 登录入口：`http://127.0.0.1:8080/login`
- 注册入口：`http://127.0.0.1:8080/register`

## 当前检索流程与评测边界

正式配置采用deepseek-flash。先执行原图谱只读检索确认可用，再对本次问题做一次受限查询理解；程序校验病名/字段后选择图谱或全文检索，理解失败回退，没有证据不生成回答。理解阶段不外发历史或资料，回答阶段仍使用已确认的最近10消息窗口。接口保留来源，普通聊天隐藏来源。

medical_text_v1保存六类149,975片段；实际全文工具查现有疾病节点properties_json中的描述、病因、预防。不是独立片段入库，也不是向量检索或多路评分融合。

本地模型、小模型环境和向量路线已停用；原归档Old/local_embedding_20261004当前不存在，不恢复或下载。历史对照及限制见 [21](../Project/08_过程_全文检索与DeepSeek路线调整.md)、[22](../Project/08_过程_全文检索与DeepSeek路线调整.md)、[23](../Project/08_过程_全文检索与DeepSeek路线调整.md)。12题真实检索对照旧2/12、新10/12，仅证明该小题集理解/检索效果，不是答案或医学准确率，不能替代最新50题评测。

## 最小 Agent 与离线演示

Flash只理解本次问题一次；后续由本地程序观察资料覆盖，缺项时选择未执行的图谱/全文查询，找齐后一次回答或明确停止。每次最多3次检索（含baseline）、一次理解和一次回答，总截止预算90秒；SDK/事务使用剩余时间且无自动重试。资料不足、来源异常或工具失败不生成猜测答案。

接口retrieval.agent返回工具、观察、证据ID、耗时、次数及停止原因；普通聊天继续隐藏来源。没有账号迁移或自动保存真实轨迹，验收材料在temp。停止理由和图文原文证据可用于独立调试展示。

在bishe目录默认离线预览：

```powershell
& '.\knowledge_graph_backend\.venv\Scripts\python.exe' -B '.\scripts\check_agent_loop.py'
```

需要真实只读验证时显式加 --read-only --report，报告须为上层temp中的新文件；需要离线重放时用 --replay 指向既有temp报告，再提供新的 --report。完整可复制命令、成功/失败与面试讲解见 [26](../Project/09_过程_Agent闭环与技术深度复审.md)。这些步骤没有新增模型调用或下载，不操作正式账号历史。
