# 合成会话上下文挑战 v1

冻结于实现前。8条合成会话，4开发/4预留。作者编写时见过预留题，不称盲测；预留题只在实现冻结后一次验收，不循环调参。任务和oracle分离，模块不得读取oracle。

仅接受显式控制表达（讨论、改查、只查预防、用表格、取消、换个话题），不宣称通用中文理解。A为最近10消息的预算匹配信息可得性代理，不是线上API或真实模型；B为独立会话状态+上下文选择。双方先按session过滤，同预算计UTF-8字节，记录估算tokens而非精确token数。评分核对信息可得性与停止，不测最终答案。C08包含大量无关助手文本以测试预算压力。

不查Neo4j、不写正式账号、不用模型或向量、不自动删除。manifest保护tasks/oracle。
