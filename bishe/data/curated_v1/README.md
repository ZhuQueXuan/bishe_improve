# 小规模疾病演示数据 curated_v1

生成日期：2026-10-03；状态：结构和来源核验通过，人工内容检查待完成。

本目录从原始 `../medical.json` 选出 40 个疾病，用于后续检索和证据展示的工程开发。1,390 个实体、2,138 条关系均可追溯到原始文件。没有连接数据库，没有使用旧处理文件生成的商品变体，也没有创建厂家、品牌或 `Producer` 节点。

**“可靠”限于加工过程、出处和结构可靠。原始医疗内容的正确性、时效性与适用范围尚未得到医学审核。** 药品、食物、病因和预防文字是原始数据记载，不能据此直接给出个体诊疗或处方建议。所有图记录均标为 `medical_review_status=not_verified`，所有疾病人工检查状态为待检查。

## 查看顺序

1. [统计报告与选取规则](../../../Project/06_过程_图谱数据工程与正式部署.md)：先看为什么选择这些疾病、排除了什么和验收结果。
2. [人工检查清单](人工检查清单.md)：按疾病查看症状、检查、药品、食物和完整的原始描述、病因与预防文字，可逐项勾选。
3. `source_records.json`：40 条完整原始记录的独立副本，包含原始行号、记录 `_id` 和分组；被排除的原始字段仍保留供审核。
4. `skipped_items.json`：999 条跳过记录及具体原因。

## 机器可读文件

| 文件 | 内容 |
| --- | --- |
| `entities.json` | 实体列表；稳定 ID、类型、名称、来源和审核状态；疾病另附原始描述、病因、预防及各自来源 |
| `relations.json` | 关系列表；稳定 ID、类型、两端实体 ID、来源和审核状态 |
| `statistics.json` | 原始字段缺失/空值/类型统计、完整度、候选决定、样本列表、关系与实体计数、源文件 SHA-256 |
| `source_audit.json` | 8,808 条疾病的选取状态、排除原因，以及全量核心列表字段的异常明细 |
| `selection_rules.json` | 固定候选顺序、8 组各 5 个的配额；完整准入规则见阶段报告及生成程序 |

每条出处包含原始文件路径、文件 SHA-256、实际行号、原始 `_id`、疾病名、字段和原始值；列表条目另含从 0 开始的索引。名称只去除两端空白，不改写、不补全被截断的名称，不做医学别名合并。共用实体的多个出处全部保留。

关系名延续旧工程的约定，包括 `recommand_drug` 等历史拼写，但文件结构是新的独立格式，**不能直接交给旧导入脚本**。`common_drug` / `recommand_drug` 等名称代表来源字段，不意味着用药已审核。后续安全导入程序需要适配该格式并保留出处和审核状态。

科室列表全部保留，未自动推断科室层级。并发疾病仅连接同样入选的疾病；范围外的并发对象不生成空壳节点。产品详情 `drug_detail` 保存在原始副本和跳过日志中，全部不参与图生成。医保、费用、患病概率、治愈率等字段暂只保留在原始副本，不进入第一版疾病属性。

## 复现和保护

项目根目录 `bishe_improve/` 下运行：

```powershell
& 'bishe/knowledge_graph_backend/.venv/Scripts/python.exe' -B 'bishe/scripts/build_curated_data.py' --verify-existing
& 'bishe/knowledge_graph_backend/.venv/Scripts/python.exe' -B 'bishe/scripts/test_curated_data.py'
```

验证模式只在内存重新生成并逐文件比较。普通生成模式拒绝覆盖已有目录，输出只允许默认 `curated_v1` 或工作区 `temp/` 中的新目录。当前目录已存在，因此普通生成会拒绝；复核使用 `--verify-existing`。程序无网络、数据库或旧处理脚本调用。

13 项自动化测试通过，包括每条实体、属性、关系与原文逐项对照；重新生成的 8 个文件逐字节一致。原始 `medical.json`、`entities.json`、`relations.json` 文件指纹核对一致。日志在 `../../../temp/curated_v1_tests.log`。

后续进展：安全导入程序的离线开发和预览测试已完成，详见 [B 阶段记录](../../../Project/06_过程_图谱数据工程与正式部署.md)。当前仍未进行真实数据库导入，也不代表医学内容审核通过。
