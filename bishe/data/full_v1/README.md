# 完整医疗数据第一版 full_v1

生成日期：2026-10-03；状态：全量文件生成、来源/结构核验及稳定复现通过，未导入任何数据库。

从全部 8,808 条原始疾病记录构建 **8,806 个疾病、27,098 个实体、301,314 条关系**。7 项全量数据测试通过；6 个机器文件重新生成后逐字节一致。原始三个 JSON 和 `curated_v1` 小样本机器文件没有修改。

与 40 个演示疾病的选择不同，全量保留缺少药品或饮食等部分字段的疾病，只跳过缺失字段，不补写内容。1 条“无标题文档”不是有效疾病名，单独排除；“胎膜早破”有 2 条记录，按可用关系字段覆盖数、可用条目数、文本长度、原始行号依次排序，保留第 8771 行作为代表，第 1739 行完整保留在排除清单中。**这是工程上的确定性去重，不能据此断言代表记录在医学上更正确。** 两条记录不自动混合；差异字段列入统计，后续重点审核。

过滤 994 个截断标签，记录 263 个同字段重复条目。宜吃/忌吃冲突的 402 个方向条目全部不入图，保留疾病和其他字段，不选择其中一个方向当作事实。163,290 个原始商品详情不参与图生成，只保留在原始副本与跳过清单，不生成厂家、品牌或 Producer / drugs_of。原始药品名称逐字保留，只去除两端空白。

## 文件

| 文件 | 内容 |
| --- | --- |
| `entities.json` | 27,098 个实体列表，稳定 ID、原名、出处、医学待核验状态；疾病保留可用描述/病因/预防及各自来源 |

```powershell
& 'bishe/knowledge_graph_backend/.venv/Scripts/python.exe' -B 'bishe/scripts/test_full_medical_data.py'
& 'bishe/knowledge_graph_backend/.venv/Scripts/python.exe' -B 'bishe/scripts/build_full_medical_data.py' --verify-existing
```
